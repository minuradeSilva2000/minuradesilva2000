## 🧪 Quality Is Part of the Build

```text
Understand the requirement
          ↓
Design the user journey
          ↓
Build the feature
          ↓
Automate important checks
          ↓
Review results and edge cases
          ↓
Iterate and improve
```

I’m interested in the whole development cycle—not only making an interface work, but also checking that the important user flows behave as expected.
